## [0.2.0] - YYYY-MM-DD

### Action required

- `strict_mode` is no longer read. A configuration that sets it sets `strict` to the same value instead. (a959bc4)

### Features

- The `trim` option drops trailing whitespace from the output. (lang, ed3ae3f)

### Bug fixes

- An error raised in a nested call names the position of the call, so a caller finds it. (cb6e77f)
- Input that is not UTF-8 returns an error instead of a panic. (9e59fb3)
- An error names the line of the input, as the Java library does. (68d547f)

### Performance

- An input used twice is parsed once, so using it again is faster. (69e8731)

### Other changes

- The README lists every option with its default. (d180dec)
